# finkalife-devlog

Imágenes del diario de desarrollo de **Finka Life** para Instagram ([@playfinkalife](https://www.instagram.com/playfinkalife/)).

- Cada publicación tiene su carpeta (`001/`, `002/`…) con 2 a 4 capturas JPEG del juego en modo limpio.
- `cola.json` es la cola de publicaciones que lee la tarea automática «Finka Life · publicar diario de Instagram». Solo se publican las entradas en estado `APROBADA`.
- Este repositorio es solo de Finka Life. Nada de ECOMA va aquí.

Un juego de Marta y Chris · RAMSYS Game Studio.
